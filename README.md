# Trợ lý Sáng kiến VIP

Ứng dụng giáo dục xây dựng nội dung sáng kiến theo hồ sơ người dùng, gồm 6 phần soạn thảo và bản xem trước hoàn chỉnh.

## Chạy tại máy

```bash
npm ci
npm run dev
```

## Triển khai

Mã nguồn có thể đưa lên GitHub và nhập trực tiếp repository vào Vercel. Cấu hình Vercel đã được khai báo trong `vercel.json`.
